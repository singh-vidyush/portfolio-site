OpsMind

A self-hosted AI operations center that investigates application telemetry. Seven agents work through metrics, logs, and traces to explain a probable root cause, confidence, and recommended fix.

FastAPILangGraphOpenTelemetryDocker
View on GitHub ↗
OpsMind is an observer, outside the application's request path. It analyzes telemetry rather than source code, uses adapters for external systems, and supports Prometheus, Loki, and Tempo. It is in early development and is not production-ready.
